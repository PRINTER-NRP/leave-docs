# เว็บดาวน์โหลดใบลาเรียน

นักศึกษาเลือกวัน → ค้นหารหัสวิชา → กดดาวน์โหลด PDF ของวิชานั้นในวันนั้น

## โครงสร้างไฟล์ใน repo

```
index.html          หน้าเว็บ
build_list.py       สคริปต์สร้างรายการไฟล์
files.json          รายการไฟล์ (สร้างจากสคริปต์ อย่าแก้เอง)
files/
  1 - จันทร์ 26 ต.ค. 2569/
    บันทึกข้อความ-ขออนุญาตลาเรียน-303431.pdf
    บันทึกข้อความ-ขออนุญาตลาเรียน-1101042.pdf
  2 - พฤหัสบดี 29 ต.ค. 2569/
    บันทึกข้อความ-ขออนุญาตลาเรียน-CWI01 4100.pdf
  ...
```

- ชื่อโฟลเดอร์: `ลำดับ - วัน วันที่` (ลำดับใช้เรียงปุ่มบนเว็บ)
- ชื่อไฟล์: ข้อความหลังขีด `-` ตัวสุดท้ายคือรหัสวิชาที่ใช้ค้นหา

## ขั้นตอนใช้งาน

1. คัดลอกโฟลเดอร์รายวันทั้งหมดไปไว้ใน `files/`
2. สร้างรายการไฟล์:
   ```
   python3 build_list.py
   ```
3. push ขึ้น GitHub แล้วเปิด Settings → Pages → Source: `Deploy from a branch` → `main` / `(root)`
4. เว็บจะอยู่ที่ `https://<username>.github.io/<ชื่อ repo>/`

ทุกครั้งที่เพิ่ม/ลบ PDF ให้รันข้อ 2 ใหม่ก่อน push

## ทดสอบบนเครื่อง

เปิด `index.html` ตรงๆ ไม่ได้ (เบราว์เซอร์บล็อกการอ่าน files.json) ให้รัน:
```
python3 -m http.server
```
แล้วเปิด http://localhost:8000

## หมายเหตุ

- ลิงก์ `.../#3` จะเปิดวันที่ 3 ไว้ให้เลย ใช้ส่งให้นักศึกษาได้
- GitHub Pages เป็นสาธารณะ ใครมีลิงก์ก็โหลดได้ อย่าใส่เอกสารที่มีข้อมูลส่วนตัว
